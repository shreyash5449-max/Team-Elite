# CivicPulse Screenshots & Visual Assets

This directory contains visual captures of the **CivicPulse** platform across its key operational states.

---

## 📸 Key Operational States

1. **`01_baseline_command_center.png`**: The default dashboard with 6 clustered incidents, 20 reports, dark Leaflet tactical map, and explainable severity scorecards.
2. **`02_compound_escalation_critical.png`**: Step 3 state where `CIV-104` evolves into a compound hazard (Severity 94, Critical Priority) with pulsing red radar beacons.
3. **`03_resource_shortage_fallback.png`**: Step 4 state demonstrating automated shortage mitigation, where the Emergency Response Vehicle is dispatched as a perimeter containment contingency.
4. **`04_citizen_report_submission.png`**: The interactive citizen reporting modal demonstrating real-time correlation against active clusters.
5. **`05_fleet_analytics_modal.png`**: Fleet readiness status table and domain breakdown charts.
